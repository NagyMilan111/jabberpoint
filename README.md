# JabberPoint

JabberpPoint is an XML based presentation player. This version of Jabberpoint has been reworked to utilize design patterns and better programming practices. Numerous bugs have also been fixed, ensuring a smooth experience. The diagrams for the application can be found within the diagrams branch.

## How to run

- Clone the repostitory, main branch
- We recommend using IntelliJ to open the project folder
- Once you open the folder, you should get a pop-up asking you if you want to load the Maven project, do this
- To start the application, run the JabberPoint class, make sure you are running jabberpoint.JabberPoint, since it is in a package
- From here you should be able to navigate the demo presentation, or load a new presentation from disk
